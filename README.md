# 📋 Feedback & Survey Form

A simple and responsive Feedback & Survey Form developed using HTML, CSS, and JavaScript.

## 🚀 Features

- 👤 User Name Input
- 📧 Email Address Input
- ⭐ 5-Star Rating System
- 📌 Favorite Feature Selection
- 💬 Feedback Text Area
- ✅ Submit Button
- 🎨 Modern Glassmorphism UI
- 📱 Responsive Design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📂 Project Structure

Feedback-Survey-Form/
│── feedback.html
│── style.css
│── script.js
│── README.md
│── screenshot.png

## ▶️ How to Run

1. Download or Clone the repository.
2. Open the project folder.
3. Double-click **feedback.html** or run it using Live Server.
4. Fill out the form and submit your feedback.
